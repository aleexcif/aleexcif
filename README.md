## BuildSolid

I created BuildSolid around a simple proposition: AI should increase a builder’s capabilities without obscuring responsibility or taking control of consequential decisions.

[BuildSolid](https://github.com/solimancifuentes/buildsolid) is an open-source, Markdown-first software factory framework and intelligence layer for building real software with AI.

It provides a portable, reviewable path from product intent and architecture through implementation, validation, and release—while keeping human judgment and decision authority explicit.

BuildSolid is currently available as a public pre-release.

## MCP systems

I also design and build systems around the Model Context Protocol, focusing on dependable integrations, bounded authority, predictable behavior, and human oversight.

This work is represented here at the practice level; individual implementations and organizational contexts remain private.

## Working principles

- Context should be governed, not merely accumulated.
- Authority should be explicit, bounded, and reviewable.
- Important claims should be connected to evidence.
- Consequential actions should remain under human control.
- Useful automation should preserve ownership and reversibility.
- Documentation should operate as part of the system—not as an afterthought.
